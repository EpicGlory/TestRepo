# Apparel Color Specs · Clean and Green Turf

Give this sheet to your embroidery / screen-print / vinyl shop.
All RGB hex values and closest Pantone matches.

## Brand Color Palette

| Brand color | Use | Hex | Pantone (closest) | Madeira Polyneon thread #* | Robison-Anton thread #* |
|---|---|---|---|---|---|
| **Fairway Green** | Primary wordmark, mow stripe center | `#2E7D32` | PMS 357 C | 1700 / 1701 | 2257 |
| **Deep Forest** | "CLEAN AND" line, dark stripe | `#1B4D1F` | PMS 5535 C | 1748 | 2287 |
| **Fresh Cut** | Accent stripe, dark-fabric variant | `#A5D6A7` | PMS 358 C | 1747 | 2280 |
| **Charcoal** | Body text, descriptor | `#2C2C2C` | PMS Black 7 C | 1800 | 2200 |
| **Limestone** | Brand background (rarely needed for apparel) | `#F4F4EF` | PMS 7527 C | 1822 | 2204 |
| **Sun Yellow** | Accent only — use sparingly | `#FFC107` | PMS 1235 C | 1670 | 2237 |
| **White** | Reverse / dark-fabric primary | `#FFFFFF` | — | 1801 | 2206 |

*Thread numbers are approximate matches. Your local shop will have their preferred equivalents and a physical thread book — let them match in person if possible. Ask them to show you the spool before they start the job.

## Fabric color recommendations

| Garment | Recommended fabric color | Design file to use |
|---|---|---|
| **Polo (sales / customer-facing)** | Heather gray, cream/off-white, or limestone | `chest_embroidery_2color.svg` |
| **Polo (premium dark option)** | **Charcoal / black** (NOT forest green) | `chest_embroidery_reverse_white.svg` |
| **T-shirt (fieldwork)** | Charcoal heather or black (hides stains) | `back_screen_print_reverse_white.svg` |
| **T-shirt (warmer weather)** | Lighter heather gray | `back_screen_print.svg` |
| **Hat (year-round dark)** | **Black or charcoal** (NOT forest green) | `hat_embroidery_reverse_white.svg` |
| **Hat (summer option)** | Cream or heather gray | `hat_embroidery.svg` |

⚠️ **About forest-green fabric:** The reverse/dark-fabric design uses **Fairway Green `#2E7D32`** for "GREEN TURF" — which is intentionally a medium-dark green to match brand identity. **This will not contrast well on forest-green shirts or hats** (same shade). If you want a forest-green base garment, ask the embroidery shop to substitute **Fresh Cut `#A5D6A7`** for visibility — same design, brighter green thread instead.

## What to tell the embroidery shop

> **"Here's a vector SVG (and PDF as backup) of our logo. We want it embroidered at [size] wide on the [left chest / hat front / back yoke]. Use [Madeira / Robison-Anton] threads in Fairway Green (PMS 357 C) and Deep Forest (PMS 5535 C). I can show you the hex codes if your software needs them. Run a digitized sample on scrap fabric first — I want to approve before you run the full batch."**

## What to tell the screen-printer

> **"Here's a vector SVG of the full back design. Spot-color print (no halftones), 3 colors max: Deep Forest, Fairway Green, Fresh Cut. Or for dark shirts, 2 colors: white + Fresh Cut. Place it 4 inches below the collar seam, centered. Approve a press proof before running the full job."**

## What to tell the vinyl / heat-press shop

> **"Heat-press vinyl in two colors: Fairway Green and Deep Forest (or substitute white for dark fabric). The design is mostly large solid shapes — no fine detail needed for vinyl. PDF attached. Production size [3" chest / 10" back]."**

## Two tips Ryan-specific (tall 3X fit)

1. **Chest placement on tall sizes**: position the chest embroidery **slightly higher** than the standard "4 inches below collar." On tall builds, the standard placement ends up sitting at belly height. Tell the embroiderer: *"2.5 inches below the collar seam, centered on the chest pocket area."*

2. **Back print scale on tall sizes**: a 10-inch back print on a regular size looks balanced; on a 3XT it can look small. Scale up to **12-14 inches** for proper proportion. The back_screen_print SVG is vector — it'll scale up cleanly.
